# Canonical Corpus Directory

Provenance-tracked primary-source datasets for each formal symbolic system will be stored here:

- `iching/` — Phase 1: 64 hexagrams, 384 line texts (*Hào từ*), *Thoán từ*, *Đại tượng*, *Tiểu tượng*, with explicit classical edition metadata.
- `ziwei/` — Phase 2: Canonical star placement tables and palace-relation rules.
- `tarot/` — Phase 3: Classical Major/Minor Arcana canonical deck schemas.
- `numerology/` — Phase 3: Pythagorean / Chaldean mapping tables.

See [docs/GUIDE.md](../docs/GUIDE.md) for provenance and data curation rules.
